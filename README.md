 # Slot Machine
    
    #### Description:
    ## Introduction
    This program is a straightforward yet illustrative simulation of the classic Slot Machine game. Its purpose is to demonstrate the fundamental mechanics of how slot machines operate and to replicate their essential logic in code.
    Slot machines are among the most recognizable games of chance worldwide. They are designed around a simple but engaging idea: a player inserts coins, spins the reels, and waits to see if the symbols align in a way that produces a win. The excitement comes from the unpredictability of the spin and the possibility of hitting a winning combination. Despite their apparent simplicity, slot machines are built on a foundation of probability and randomness, which ensures fairness while also keeping the game entertaining.
    At their core, a slot machine consists of reels filled with symbols. These reels spin independently and stop at random positions. When the reels align in certain patterns—commonly referred to as winning combinations—the player earns a payout. Winning combinations can vary depending on the design of the machine, but they usually include matches such as three identical symbols in a row or two matching symbols with a special symbol. Each combination has its own payout value, which determines how many coins the player receives.
    The appeal of slot machines lies in their balance between simplicity and chance. Every spin is independent, meaning the outcome of one spin does not affect the next. This independence is what makes the game fair and unpredictable. Players know that they cannot predict or control the reels, but the possibility of winning keeps them engaged. The randomness is usually generated by algorithms or mechanical systems, and in digital simulations like this project, the randomness is handled by the programming library random .

    ## Code Structure
    Moving to the structure of the code, the program is organized around four main functions:
    - get_coins – Prompts the player to enter the number of coins they wish to start with. It validates the input and returns the value to the main function.
    - playing – Acts as the central hub of the program. It accepts the coin balance, asks the player how much they want to bet per spin, and then calls spin_reels to generate a random combination of symbols. The result is passed to check_win, which determines whether the player has won. It then displays both the spin outcome and the profit, and asks the player if they wish to continue.
    - spin_reels – Uses the Python random library to simulate spinning reels. It contains three lists, each representing a reel with its own sequence and length of symbols. A random selection from each list produces the final combination, which is returned for evaluation.
    - check_win – Compares the generated combination against predefined winning patterns. It first checks for three-of-a-kind matches, then two-of-a-kind. Each winning condition is associated with a payout value, which is returned to calculate the player’s profit.
    Finally, the main function orchestrates the overall execution. It prints the game’s title using the pyfiglet library, retrieves the starting coins via get_coins, and launches the playing function to manage gameplay. When the player finishes, the program displays their remaining balance and concludes with a clear GAME OVER message.
